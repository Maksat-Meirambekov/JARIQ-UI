# ☀️ Жарық UI (Jaryq UI) — Қазақ тіліндегі халықтық Android жүйесі

**Жарық UI** — бұл кез келген Android смартфонына орнатуға болатын жеңіл, түсінікті және толықтай қазақ тіліндегі ашық (Open Source) қабықша (лаунчер). 

Біздің мақсатымыз — технологияны әрбір қазақстандыққа, әсіресе үлкен буын өкілдеріне өз ана тілінде барынша ыңғайлы әрі қолжетімді ету.

---

### ✨ Негізгі мүмкіндіктері
* **Таза қазақша интерфейс:** Машиналық аудармасыз, күнделікті өмірге түсінікті тіл.
* **Үлкендерге арналған режим:** Ірі әріптер, жылдам қоңырау шалу және хабарлама жазу батырмалары.
* **Жылдам іздеу:** Барлық қосымшаларды бір мезетте табу мүмкіндігі.
* **Көзге жайлы дизайн:** Түнгі аспан мен күн сәулесінің үйлесіміндегі заманауи стиль.

---

### 📥 Жүктеп алу (Скачать APK)
1. Жоғарғы мәзірден **Actions** (Действия) бөліміне өтіңіз.
2. Соңғы жасыл белгімен тұрған құрастыруды ашып, төменгі жақтағы **Artifacts** бөлімінен `JaryqUI-Launcher` файлын жүктеп алыңыз.
3. Смартфоныңызға орнатып, «Негізгі экран» (Главный экран) ретінде **Жарық UI** таңдаңыз.

---

### 🤝 Жобаны қолдау (Поддержать проект)
Жоба тегін таратылады және халықтың қолдауымен дамиды. Егер **Жарық UI** сізге пайдалы болса, дамуына үлес қоса аласыз:
* Жоғарыдағы **⭐ Star** батырмасын басыңыз.
* Қаржылай қолдау көрсету үшін осы беттегі **Sponsor** батырмасын пайдаланыңыз.

---

### 👨‍💻 Әзірлеушілерге (Для разработчиков)
Жоба **Kotlin** және **Jetpack Compose** технологияларымен жасалған. Егер кодты жақсартуға, жаңа виджеттер немесе қазақша дауыстық көмекші қосуға үлес қосқыңыз келсе — **Pull Request** жіберіңіз!
